# Как выложить КальКа в интернет очень просто

Ниже только самые простые шаги.

Твоя цель:

1. загрузить код на GitHub
2. подключить сайт к Vercel
3. привязать сайт к Supabase
4. дать людям ссылку

Если совсем коротко:

`GitHub = место, где лежит код`

`Vercel = место, где сайт появится в интернете`

`Supabase = база данных и вход по логину/паролю`

## Самый простой план

### Шаг 1. Создать GitHub

Если у тебя ещё нет аккаунта:

1. Открой [https://github.com](https://github.com)
2. Нажми `Sign up`
3. Создай аккаунт

Если аккаунт уже есть, просто войди.

---

### Шаг 2. Загрузить проект на GitHub

Тебе нужно будет:

1. создать на GitHub новый `Private` репозиторий
2. загрузить туда папку проекта

Если ты не умеешь это делать, самый простой вариант потом будет такой:

1. открыть `GitHub Desktop`
2. выбрать папку проекта
3. нажать `Publish repository`

Важно:

Репозиторий лучше делать `Private`.

Это значит:

`код видишь только ты`

---

### Шаг 3. Выложить сайт через Vercel

После GitHub:

1. Открой [https://vercel.com](https://vercel.com)
2. Нажми `Continue with GitHub`
3. Разреши доступ
4. Нажми `Add New Project`
5. Выбери свой репозиторий с КальКа
6. Нажми `Deploy`

И всё.

После этого Vercel сам даст тебе ссылку на сайт.

Пример:

`https://kalka.vercel.app`

---

### Шаг 4. Привязать сайт к Supabase

После того как Vercel даст ссылку:

1. Открой Supabase
2. Слева нажми `Authentication`
3. Потом `URL Configuration`
4. В `Site URL` вставь ссылку сайта из Vercel
5. В `Redirect URLs` тоже вставь эту же ссылку
6. Сохрани

---

### Шаг 5. Проверить вход

Теперь:

1. открой ссылку сайта
2. войди своим логином и паролем
3. проверь, что всё открывается

---

### Шаг 6. Создать пользователей

Когда всё работает:

1. открой `Supabase`
2. слева нажми `Authentication`
3. потом `Users`
4. нажми `Add user`
5. создай пользователя

Потом дашь этому человеку:

1. ссылку на сайт
2. email
3. пароль

И он сможет работать.

## Что делать прямо перед запуском пользователей

3. каталог открывается
