## 2. Создай первого пользователя

Открой `Supabase -> Authentication -> Users -> Add user`.

Заполни:
- Email: твой email
- Password: свой пароль
- Auto Confirm User: `ON`

В `User Metadata` вставь:

```json
{
  "first_name": "Михаил",
  "last_name": "Крючков",
  "company": "КальКа",
  "role": "owner",
  "status": "active"
}
```

## 3. Открой сайт и войди

После входа:
- сессия сохранится через Supabase;
- профиль подтянется автоматически;
- если в legacy-хранилище уже есть данные, приложение попытается перенести их в `app_state`.

## Если вход не работает

Проверь:
- SQL действительно выполнен без ошибок;
- пользователь создан именно в `Authentication -> Users`;
- в metadata есть `role` и `status`;
- `status` = `active`.
